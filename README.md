# 讓愛繼續行走｜香港遺產規劃

這是一個為六十五歲以上香港居民設計的本機遺產意向梳理工具。使用者沿着六幕香港生活場景整理牽掛，最後可下載、分享或列印「安心摘要」。網站不會把選擇或聯絡資料上載至服務端。

## 正式版特點

- 完整每秒二十四格影片隨捲動進度線性對應，不使用場景吸附。
- 桌面及手機分別載入七百二十像素及五百四十像素影片，不會同時下載兩個版本。
- 減少動態、節省數據、手動選擇或影片失敗時，改用六張靜態代表圖。
- 六幕文字按「章名、提問、涉及事項、安心清單」四段緩慢浮現。
- 手機直向、橫向及矮螢幕均有獨立閱讀佈局；可見正文字體不少於二十像素，操作目標不少於四十八像素。
- 安心清單以版本化本機儲存保存，支援下載、原生分享、複製備援及列印。
- 正式機構、顧問資格及資料安排未核實前，不顯示虛構聯絡方法，也不收集個人資料。

## 核心結構

```text
├─ index.html                 網站內容及香港官方查證入口
├─ styles.css                正式視覺、長者無障礙及多裝置佈局
├─ script.js                 六幕、影片捲動及安心清單邏輯
├─ assets/
│  ├─ media/                 兩個影片版本、六張靜態圖及分享圖
│  └─ vendor/                本機保存的動畫程式庫
├─ scripts/build.cjs         正式公開檔案白名單建立程式
├─ tests/                    瀏覽器、媒體、私隱及部署驗證
├─ docs/ENGINEERING_LOG.md   設計與技術決策紀錄
├─ docs/DEPLOYMENT.md        發布及回復步驟
└─ PROJECT_HANDOFF.md        跨對話交接狀態
```

原有二百四十張圖片序列仍可保留在本機來源目錄，但已從版本追蹤、正式成品及 Vercel 上載範圍移除。

## 本機預覽

已安裝 Node.js 及套件後，在專案根目錄執行：

```powershell
pnpm install
pnpm run serve
```

然後開啟 <http://127.0.0.1:8765>。測試伺服器支援影片所需的位元組範圍回應；不建議直接雙擊首頁檔案。

## 建立與驗證

```powershell
pnpm run build
pnpm test
```

建立程式只把公開白名單複製至 `dist`。完整驗證涵蓋影片線性映射、首屏延後載入、動態降級、六幕慢放、文案次序、安心清單、下載、分享、列印、私隱邊界、字體、行距、觸控目標、鍵盤及八種代表畫面尺寸。

## 正式服務邊界

以下資料仍待業務方確認：

- 正式機構名稱及香港聯絡方法。
- 顧問姓名、職銜、資格、發證機構及核實編號。
- 正式預約接收端點及處理資料的人士。
- 個人資料用途、保存期限、查閱及更正途徑。
- 經香港法律及私隱專業人士核對的正式條款。

上述資料完成核實前，網站可正式用作本機梳理工具，但不會聲稱已提交免費諮詢預約。
