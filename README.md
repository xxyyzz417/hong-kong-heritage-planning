# 香港遺產規劃沉浸式網頁

此靜態網站以六個香港生活場景，引導六十五歲以上使用者逐步梳理資產與遺產分配意向。網站採用原生 `HTML`、`CSS`、`JavaScript`，並以 `GSAP ScrollTrigger` 驅動二百四十張序列幀。

## 目錄結構

```text
web for heritage plan/
├─ index.html
├─ styles.css
├─ script.js
├─ favicon.svg
├─ README.md
├─ assets/
│  └─ vendor/
│     ├─ gsap.min.js
│     └─ ScrollTrigger.min.js
├─ design/
│  └─ ui-concept-treasure-map-v1.png
└─ video split to png for scrolltriger/
   ├─ ezgif-frame-001.png
   ├─ ……
   └─ ezgif-frame-240.png
```

影格目錄及檔名不可隨意更改。如需更改，請同步修改 `script.js` 內的 `影格目錄`、`總幀數`及 `影格路徑`。

動畫程式庫已放入網站資源目錄，部署及本機預覽均毋須依賴外部內容傳遞服務。`design` 目錄內的圖像只作介面設計參考，不會在網站載入。

## 本機預覽

不可直接雙擊開啟，應以本機靜態伺服器預覽。可在此目錄執行：

```powershell
python -m http.server 8000
```

然後在瀏覽器開啟 `http://localhost:8000/`。

## 序列幀映射

核心公式為：

```text
當前幀 = 向下取整（動畫進度 ×（總幀數 − 一））＋一
```

捲動進度直接線性對應全二百四十幀，不使用場景吸附、停靠減速或分段緩動；使用者捲動多少，序列幀及視覺進度線便前進多少。完整時間軸保留約十三個視窗高度的捲動距離。一般桌面裝置預載目標影格前後各十二幀，一般流動裝置預載前後各八幀，只有開啟節省數據時才每兩幀取樣一次。繪製工作由瀏覽器的動畫幀請求統一節流。

六個場景圓點只提供自選跳轉，不會在捲動停止後自動拉回場景錨點。第五幕的點擊錨點使用第一百九十六幀。文案沒有資訊卡底色；標題、提問、資產提示及選擇按鈕各自浮在畫面上。`文案位置關鍵點`會按目前序列中人物的移動軌跡作線性插值，為每一個實際繪製影格計算獨立位置，並在人物密集的第二、第三及第五幕把文案分散至畫面四周。

「返回上一幕」及「前往下一幕」會以四點二秒固定速度線性播放至相鄰場景；播放期間兩個按鈕會暫時停用，避免重複導航。每次進入新一幕，文案依「標題與情緒、提問、涉及安排、安心清單選項」四段浮現；每段使用一秒緩慢浮起，段落之間保留約半秒閱讀停頓，完整序列約五點六秒。流動裝置使用由上至下的固定閱讀軸，避免各區塊重疊；開啟減少動態效果時會即時顯示完整內容。

開篇使用第一幀作全幅生活影像，配合深色遮罩、跨畫面巨型標題、低飽和米金色資訊標籤及圓形旅程入口。視覺語言取材自家書、舊照片及資產文件的層疊質感，不會載入外部網站資源。

## 正式聯絡資料

以下資料尚未提供，因此網站目前以「待確認」顯示，且不會傳送回電資料：

- 正式聯絡電話
- 正式預約接收方式或服務端點
- 所屬機構、專員職銜及專業資格核實資料
- 私隱聲明中的資料保存期限、查閱及更正方法

收到正式資料後，應先完成合規核對，再啟用「立即致電」及回電提交功能。不得填入示範電話或虛構資格。

## 發佈至 GitHub Pages

1. 在 GitHub 建立一個新的儲存庫。
2. 將本目錄全部檔案及影格目錄提交至預設分支。
3. 開啟儲存庫的「設定」，再選擇「頁面」。
4. 在「建置及部署」中選擇從分支發佈。
5. 選擇預設分支及根目錄，然後儲存。
6. 等待部署完成，再以系統提供的網址檢查六幕跳轉、影格載入、手機版及鍵盤操作。

每張影格均低於單一檔案大小限制，但整套影格容量較大。正式上線前宜進一步壓縮影格，並以實際流動網絡測試首次載入時間。

## 上線前檢查

- 所有用戶可見文案維持繁體中文。
- 正文字體不少於二十像素，互動目標不少於四十八乘四十八像素。
- 鍵盤可操作所有按鈕，焦點外框清晰可見。
- 開啟「減少動態效果」後，只在六個代表影格之間切換。
- 第一幕不顯示上一幕按鈕或替代文字。
- 已瀏覽場景不顯示勾號，只有當前場景會突出顯示。
- 不會自動播放音效，也不使用快速閃爍動畫。
