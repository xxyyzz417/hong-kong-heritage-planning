# 讓愛繼續行走｜香港遺產規劃

這是一個為六十五歲以上香港居民設計的本機遺產意向梳理工具。使用者沿着六幕香港生活場景整理牽掛，最後可下載、分享或列印「安心摘要」。網站不會把選擇或聯絡資料上載至服務端。

## 正式版特點

- 十二幀每秒的 WebP 圖片序列隨捲動進度線性對應，不使用場景吸附。
- 九百六十張影格合計約四十四點七百萬位元組；目前影格與下一影格以透明度混合，並優先預載鄰近影格。
- 減少動態或節省數據時只顯示六幕代表影格。
- 六幕文字按「章名、提問、涉及事項、安心清單」四段緩慢浮現。
- 手機直向、橫向及矮螢幕均有獨立閱讀佈局；可見正文字體不少於二十像素，操作目標不少於四十八像素。
- 安心清單以版本化本機儲存保存，支援下載、原生分享、複製備援及列印。
- 正式機構、顧問資格及資料安排未核實前，不顯示虛構聯絡方法，也不收集個人資料。

## 核心結構

```text
├─ index.html                 網站內容及香港官方查證入口
├─ styles.css                正式視覺、長者無障礙及多裝置佈局
├─ script.js                 六幕、圖片序列捲動及安心清單邏輯
├─ assets/
│  ├─ frames/                九百六十張 WebP 時間軸影格
│  ├─ media/                 保留供既有 Vercel 部署使用的影片及靜態圖
│  └─ vendor/                本機保存的動畫程式庫
├─ scripts/build.cjs         正式公開檔案白名單建立程式
├─ tests/                    瀏覽器、媒體、私隱及部署驗證
├─ docs/ENGINEERING_LOG.md   設計與技術決策紀錄
├─ docs/DEPLOYMENT.md        發布及回復步驟
└─ PROJECT_HANDOFF.md        跨對話交接狀態
```

原有二百四十張 PNG 等效每秒三格；正式時間軸改為九百六十張 WebP，幀率提高四倍而正式成品仍低於五十百萬位元組。

## 本機預覽

已安裝 Node.js 及套件後，在專案根目錄執行：

```powershell
pnpm install
pnpm run serve
```

然後開啟 <http://127.0.0.1:8765>。不建議直接雙擊首頁檔案。

## 建立與驗證

```powershell
pnpm run build
pnpm test
```

建立程式只把公開白名單複製至 `dist`。完整驗證涵蓋圖片序列線性映射、鄰近影格預載、減少動態、六幕慢放、文案次序、安心清單、下載、分享、列印、私隱邊界、字體、行距、觸控目標、鍵盤及多種代表畫面尺寸。

## 正式服務邊界

以下資料仍待業務方確認：

- 正式機構名稱及香港聯絡方法。
- 顧問姓名、職銜、資格、發證機構及核實編號。
- 正式預約接收端點及處理資料的人士。
- 個人資料用途、保存期限、查閱及更正途徑。
- 經香港法律及私隱專業人士核對的正式條款。

上述資料完成核實前，網站可正式用作本機梳理工具，但不會聲稱已提交免費諮詢預約。
